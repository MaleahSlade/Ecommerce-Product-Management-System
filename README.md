E-Commerce System

A TypeScript-based e-commerce application that retrieves product data from an external API and calculates product discounts, taxes, and final prices.

Features

* Fetches product data asynchronously using async/await.
* Models product information using a TypeScript class.
* Calculates product discounts and category-based taxes.
* Handles API errors and invalid responses.
* Displays product details and final prices in the console.

Technologies

* TypeScript
* Node.js
* DummyJSON Products API
